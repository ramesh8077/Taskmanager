# Demo Video Recording Guide

To submit your project successfully, you need to record a demo video (max 1GB). Follow this script and guide to create a professional presentation.

## Preparation
1. **Tool**: Use a screen recorder like OBS Studio, Loom, or Windows Game Bar (Win+G).
2. **Environment**: Ensure your backend (`server.js`) and frontend (`npm run dev`) are running.
3. **Data**: Have some dummy tasks and tickets already created so the dashboard looks full.

## Video Script (Step-by-Step)

### 1. Introduction (0:00 - 0:30)
*   **Action**: Show the Landing/Login Page.
*   **What to say**: "Hello, this is my Team Task Manager and Helpdesk System. It is a full-stack application built using Next.js and Node.js. It helps teams manage their internal tasks and customer support tickets in one place."

### 2. Authentication (0:30 - 1:15)
*   **Action**: Log in with an existing account or register a new one. Show the toast notifications (Sonner) when you log in.
*   **What to say**: "The app features secure JWT-based authentication. As you can see, I'm logging in, and the session is managed securely via cookies. Once authenticated, we are redirected to the main dashboard."

### 3. Dashboard Overview (1:15 - 2:00)
*   **Action**: Scroll through the Dashboard. Point out the summary cards (Total Tasks, Pending Tickets, etc.).
*   **What to say**: "This is the central hub. We have a clean, professional table layout for viewing all items. It's designed to be responsive and works perfectly on different screen sizes, including tablets and small laptops."

### 4. Task & Project Management (2:00 - 3:30)
*   **Action**: Navigate to the Tasks section. Create a new task or update an existing one.
*   **What to say**: "Teams can create projects and assign tasks. You can set priorities like High or Low and track the status. The UI is built with Tailwind CSS for a premium feel."

### 5. Helpdesk / Support Tickets (3:30 - 5:00)
*   **Action**: Go to the Ticket Dashboard. Show how a ticket can be filtered or its status changed (e.g., from 'Open' to 'Resolved').
*   **What to say**: "The Helpdesk module is a key feature. It allows agents to handle support requests. We can track the root cause of issues and maintain an audit history for every ticket. This makes the system ideal for support teams."

### 6. Conclusion (5:00 - 5:30)
*   **Action**: Show the mobile responsiveness or the Light/Dark mode if implemented.
*   **What to say**: "The system is robust, secure, and ready for production. Thank you for watching the demo."

## Tips for a Great Video
- **Speak Clearly**: Use a good microphone if possible.
- **Keep it Moving**: Don't spend too much time on one screen.
- **Full Screen**: Record in full-screen mode for clarity.
- **Resolution**: Record in 1080p if possible, but keep the file size under 1GB.
