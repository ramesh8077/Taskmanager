# Project Demo Video Script (Hindi)

Aap is script ko padh kar apna video record kar sakte hain. Isme saari details cover ki gayi hain.

---

## 1. Introduction & Sorry Note (0:00 - 1:00)
**Action**: Login screen par cursor rakhein.
**Script (Kya bolna hai)**:
"Namaste, mera naam [Aapka Naam] hai. Sabse pehle main ek chhota sa 'Sorry Note' dena chahta hoon. Company mein kaam (workload) zyada hone ki wajah se mujhe is project ko submit karne mein thodi deri ho gayi, kyunki mujhe limited time hi mil pa raha tha. Uske liye main maafi chahta hoon.

Lekin, maine is project ko poori mehnat se banaya hai. Yeh ek 'Team Task Manager aur Helpdesk System' hai. Aaj main aapko iska full detail demo dikhaunga."

---

## 2. Authentication (Login/Register) (1:00 - 2:00)
**Action**: Login karke dashboard par jaayein.
**Script**:
"Sabse pehle hum login page par hain. Maine isme secure JWT-based authentication use kiya hai. Login karne ke baad hum direct Dashboard par land karte hain. Aap dekh sakte hain ki 'Toast Notifications' ke zariye user ko real-time feedback bhi milta hai."

---

## 3. Dashboard & Theme (2:00 - 3:00)
**Action**: Dark/Light mode toggle karein aur stats dikhayein.
**Script**:
"Yeh hamara main Dashboard hai. Interface ko bahut hi modern aur clean rakha gaya hai. Yahan top par aap 'Theme Toggle' dekh sakte hain, jisse hum Light mode aur Dark mode ke beech switch kar sakte hain. 

Dashboard par humein project ki summary dikhti hai: jaise ki total kitne Projects hain, kitne Tasks pending hain, aur kitne Members team mein hain. Yahan 'Overdue' tasks ka bhi alag se count dikhta hai taaki deadline miss na ho."

---

## 4. Task Management (3:00 - 5:00)
**Action**: 'Tasks' tab mein jaayein, ek task ka status badlein ya filters dikhayein.
**Script**:
"Tasks section mein hum har task ki details dekh sakte hain: Task ID, Assignee, Priority, aur Status. 
*   Hum yahan se naya Project aur naya Task create kar sakte hain. 
*   Tasks ko Filter karne ke liye advance options hain—aap Priority (Low, Medium, High, Urgent) ya Status ke basis par tasks search kar sakte hain.
*   Admin kisi bhi task ki priority aur status ko table se hi update kar sakta hai.
*   Har task ki ek 'Activity Timeline' bhi hai jo dikhati hai ki kab kisne kya change kiya."

---

## 5. Helpdesk System (Full Detail) (5:00 - 7:30)
**Action**: 'Tickets' tab par click karein. Ek ticket khol kar dikhayein.
**Script**:
"Ab aate hain is project ke sabse important feature par—'Helpdesk System'. Yeh module team members ki queries ya problems solve karne ke liye hai.
*   Yahan tickets ka ek professional table view hai jisme hum Multiple tickets ko ek saath select karke 'Bulk Actions' bhi le sakte hain (jaise unhe close karna).
*   Jab hum kisi ticket par click karte hain, toh uski poori details khulti hain—Description, Screenshot, aur uski poori 'Activity History'.
*   Yahan ek 'Comment System' bhi hai jahan team members aapas mein discuss kar sakte hain.
*   Sabse khaas baat: Ticket resolve karte waqt 'Root Cause Analysis' mandatary (zaroori) hai, taaki humein pata chale ki issue kyun aaya tha."

---

## 6. Technology Stack & Conclusion (7:30 - 8:30)
**Action**: Dashboard ko scroll karte hue video end karein.
**Script**:
"Is project ko banane ke liye maine:
*   **Frontend** mein Next.js aur Tailwind CSS ka use kiya hai premium design ke liye.
*   **Backend** mein Node.js aur Express use kiya hai.
*   **Database** ke liye Sequelize ORM ka use kiya hai.

Yeh system puri tarah se responsive hai aur Jio Laptop jaise 768px screens par bhi perfectly chalta hai. 

Thank you so much mujhe yeh mauka dene ke liye. Umeed hai aapko mera kaam pasand aayega."

---

## Tips for Recording:
1. **Screen Recorder**: 'OBS Studio' use karein.
2. **Cursor**: Mouse cursor ko slow move karein taaki dekhne waale ko samajh aaye aap kahan click kar rahe hain.
3. **Voice**: Thoda dheere aur saaf boleinh.
